# WindowsDoProgram

**Русский** | [English](README.md)

Скрипт для настройки Windows 10/11 после чистой установки. Всё, что он делает, описано в одном файле `config.json`: правите его один раз, потом после каждой переустановки запускаете `Run.bat` и получаете одинаково настроенную систему — программы, приватность, Проводник, курсоры, тема.

## Возможности

- **Программы** — установка через winget, тихая установка exe/msi с диска, список того, что ставится руками (со ссылками).
- **Приватность** — телеметрия, рекламный идентификатор, журнал действий, Cortana, Bing в Пуске, Copilot, Recall.
- **Удаление встроенных приложений** — Xbox, Bing, Teams, Clipchamp, Пасьянс и прочее (возвращаются через Microsoft Store). OneDrive по желанию.
- **Проводник и панель задач** — расширения, скрытые файлы, классическое контекстное меню, компактный вид, левая панель, виджеты, поиск, секунды в часах, «Рекомендуем» в Пуске.
- **Оформление** — схема курсоров и сторонняя тема `.msstyles` (с UltraUXThemePatcher).
- **Система** — план питания, таймауты экрана и сна, длинные пути, история буфера обмена, залипание клавиш, режим разработчика, часовой пояс.
- **Выбор пунктов** — у каждого модуля есть список с галочками: отметили только нужное и запустили.
- **Безопасно** — точка восстановления перед изменениями, режим DryRun, лог каждого запуска.

## Структура

```
WindowsDoProgram\
├─ Run.bat            запуск двойным кликом (сам запросит права администратора)
├─ Setup.ps1          главный скрипт: меню, загрузка конфига, запуск модулей
├─ config.json        ВСЕ настройки — редактируйте этот файл
├─ modules\
│   ├─ Common.ps1     общие функции: лог, реестр, службы, dry-run
│   ├─ Menu.ps1       список с галочками: выбор пунктов внутри модуля
│   ├─ Apps.ps1       установка программ через winget и с диска
│   ├─ Privacy.ps1    телеметрия, реклама, Cortana, Copilot, Recall
│   ├─ Debloat.ps1    удаление встроенных приложений, OneDrive
│   ├─ Explorer.ps1   Проводник, панель задач, тема, меню Пуск
│   ├─ Theme.ps1      курсоры и тема из resources
│   └─ System.ps1     план питания, сон, длинные пути, буфер обмена и т.д.
├─ resources\         то, что ставится с диска, а не из winget (см. resources\README.md)
│   ├─ installers\        exe/msi — ставятся тихо модулем apps
│   ├─ cursors\           схемы курсоров (dark / light)
│   ├─ themes\EJECT\      тема EJECT + UltraUXThemePatcher + Themes Fix.reg
│   └─ scripts\           bat для ручного запуска
└─ logs\              лог каждого запуска
```

## Быстрый старт

1. Скопируйте папку на флешку или в облако, чтобы она переживала переустановку.
2. После установки Windows дважды кликните `Run.bat`. Появится меню:

```
[1] Выполнить ВСЁ по config.json (без вопросов)
[2] Установка программ
[3] Приватность и телеметрия
[4] Удаление встроенных приложений
[5] Проводник, панель задач, внешний вид
[6] Оформление: курсоры и тема EJECT
[7] Система: питание и параметры
[D] Переключить режим проверки (DryRun)
[C] Открыть config.json в Блокноте
[L] Открыть папку с логами
[0] Выход
```

- **[1]** выполняет всё по конфигу без вопросов.
- **[2]–[7]** открывают список пунктов модуля с галочками (см. ниже).
- **[D]** — режим проверки: скрипт только печатает, что сделал бы, с пометкой `[DRY]`, ничего не меняя.
- **[C]** — открыть `config.json` в Блокноте. **[L]** — открыть папку с логами.

### Выбор пунктов внутри модуля

Галочки изначально стоят так, как записано в `config.json`:

```
   Установка программ
   -- Через winget --
   [x]   1. Firefox (русский)  (Mozilla.Firefox.ru)      [x]  14. Everything  (voidtools.Everything)
   [x]   2. Telegram  (Telegram.TelegramDesktop)         [ ]  15. KeePassXC  (KeePassXCTeam.KeePassXC)
   ...
   Выбрано: 24 из 27
   [A] все   [N] ничего   [I] инвертировать   [S] ЗАПУСТИТЬ выбранное   [0] назад
   Ввод: 15, 20-23
```

- Введите номер (или несколько через запятую, или диапазон `5-12`), чтобы включить или выключить пункт.
- Пункты со значением (курсоры `dark`/`light`, план питания `high`/`balanced`/`ultimate`, поиск на панели задач) переключаются по кругу повторным вводом номера; последнее положение — «не менять».
- Пункты `[-]` не заданы в `config.json` (например, часовой пояс) — впишите значение в конфиг, и они появятся.
- `S` запускает модуль только с отмеченным. Выбор действует на один запуск, `config.json` не меняется.

### Без меню, из PowerShell

```powershell
.\Setup.ps1 -All                       # всё по конфигу
.\Setup.ps1 -Modules privacy,explorer  # только выбранные модули
.\Setup.ps1 -All -DryRun               # показать, что будет сделано, ничего не меняя
.\Setup.ps1 -All -NoRestorePoint       # без точки восстановления
.\Setup.ps1 -ConfigPath D:\my.json     # другой конфиг
```

Модули: `apps`, `privacy`, `debloat`, `explorer`, `theme`, `system`.

## Настройка config.json

- Строки, начинающиеся с `//`, и хвосты строк после `//` — комментарии.
- `true` — применить, `false` — пропустить. У каждого модуля есть свой `"enabled"`.
- Висящая запятая после последнего элемента списка допустима.

### Программы через winget

Найдите ID пакета:

```powershell
winget search "chrome"
```

Впишите в `apps.winget`:

```json
"winget": [
  "Google.Chrome",
  { "id": "7zip.7zip", "name": "7-Zip" },
  { "id": "Microsoft.VisualStudioCode", "args": "--scope machine" },
  { "id": "Discord.Discord", "enabled": false }
]
```

Уже установленные программы пропускаются.

### Установщики с диска

Секция `apps.local` — exe/msi из `resources\installers`, ставятся тихо:

```json
"local": [
  { "name": "MiniBin", "path": "resources\\installers\\MiniBin-6.1.1.1-Setup.exe", "args": "/S", "detect": "MiniBin" }
]
```

- `args` — ключи тихой установки: NSIS `/S`, Inno Setup `/VERYSILENT /NORESTART`; для msi скрипт сам добавляет `/qn`.
- `detect` — часть названия в «Установка и удаление программ» или путь к файлу (`%ProgramFiles(x86)%\...`). Если найдено — пропуск.

### Программы, которых нет в winget

Секция `apps.manual` — что ставится руками. В конце работы модуля скрипт печатает этот список и, если `openManualLinks: true`, открывает ссылки в браузере.

```json
"manual": [
  { "name": "Ocypus Digital", "url": "https://www.ocypus.com/download", "note": "скачать и установить" }
]
```

### Удаление встроенных приложений

Посмотреть, что установлено:

```powershell
Get-AppxPackage | Select-Object Name | Sort-Object Name
```

Имя добавьте в `debloat.apps`. Поддерживаются маски, например `"*Xbox*"`. Удаление Xbox-пакетов ломает вход в игры из Microsoft Store, которым нужен Xbox-аккаунт — если играете в такие, уберите их из списка.

### Курсоры и тема (модуль theme)

```json
"theme": {
  "enabled": true,
  "cursors": "dark",                    // "dark" | "light" | "" — папка в resources\cursors
  "cursorsFolder": "resources\\cursors",
  "eject": { "enabled": true, "folder": "resources\\themes\\EJECT",
             "patchUxTheme": true, "themesFix": true, "themesService": true, "apply": true }
}
```

- **Курсоры** копируются в `C:\Windows\Cursors\<схема>`, схема прописывается в реестр и применяется сразу (то же, что «ПКМ → Установить» на `Install.inf`).
- **Тема** — сторонний `.msstyles`, Windows без патча её не примет. Скрипт тихо ставит `UltraUXThemePatcher.exe`, копирует тему в `C:\Windows\Resources\Themes`, применяет `Themes Fix.reg` (тема не трогает значки, курсоры и обои) и включает службу «Темы».
- Если патчер только что установлен — **нужна перезагрузка**; тема применится сама при следующем входе. Если патчер уже стоял — тема применяется сразу.
- UltraUXThemePatcher меняет системные файлы; после крупных обновлений Windows патч может слететь — тогда снова запустите модуль `theme`.

### Проводник

Ключи секции `explorer` соответствуют пунктам в списке. Всё, что делал «Apply All» в `resources\scripts\Explorer config.bat`, здесь: `compactView`, `hideStatusBar`, `hideHomeInNavPane`, `hideGalleryInNavPane`, `hideNetworkInNavPane`, `showRecycleBinInNavPane`, `hideDesktopRecycleBin`, `hideRecentFilesInExplorer`, `classicContextMenu`, `openExplorerToThisPC`.

## Безопасность

- Перед изменениями создаётся точка восстановления (отключается `createRestorePoint: false` или ключом `-NoRestorePoint`).
- Режим `-DryRun` печатает каждое действие с пометкой `[DRY]`, не трогая систему.
- Скрипт не отключает Defender, UAC, Windows Update. Из интернета ставится только то, что есть в winget; с диска — только файлы из `resources`.
- Удалённые встроенные приложения возвращаются через Microsoft Store.
- Каждый запуск пишет лог в `logs\`.

## Что применяется после перезагрузки

Телеметрия, план питания и большая часть параметров работают сразу. Тема, контекстное меню и панель задач — после перезапуска Проводника (делается автоматически). Длинные пути, режим разработчика, подробный вход, UltraUXThemePatcher и тема EJECT — после перезагрузки.

## Требования

- Windows 10 / 11, PowerShell 5.1 (встроен).
- winget («Установщик приложений» из Microsoft Store) — для модуля `apps`.
- Права администратора — `Run.bat` запросит сам.
